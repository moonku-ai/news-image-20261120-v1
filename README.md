A pure-Python-stdlib program that draws one 1024x1024 PNG summing up the world news of Friday 20 November 2026: Cyclone Akvan's landfall in Odisha, the Trump-Xi-Putin trilateral aftermath, the ICJ's Myanmar genocide verdict, and more.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, deterministic, no network) to `$MAKEFUN_OUTPUT_DIR` or `/output`. Tests: `python3 -m unittest test_main -v`.
